cosmocore.spectrum_key module
=============================

Canonical key types for spectra and Fisher blocks. Defines
:class:`SpectrumKey`, the structural :class:`SpectrumKind` enum (ordered
slot pairs), and the :class:`SymmetryMode` flag controlling how
cross-component E/B spectra are emitted. CMB-friendly aliases
(``TT``/``EE``/``BB``/``EB``/``BE``/``TE``/``ET``/``TB``/``BT``) live in
:mod:`cosmocore.conventions.cmb`.
