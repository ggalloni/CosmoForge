CosmoForge uses Sphinx to build its documentation. The latest docs are available online:

- **[Online Documentation](https://ggalloni.github.io/CosmoForge/)**

## Building Locally

To build the documentation locally:

```bash
cd docs
make html
```

This will generate HTML files in `docs/build/html/`.

## Editing Docs

- Source files are in `docs/source/`
- Main index: `docs/source/index.rst`
- API reference: `docs/source/api/`
- Tutorials: `docs/source/tutorials/`
