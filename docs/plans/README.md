# Plans

Implementation plans live in `.claude/plans/`, not here. This directory exists only as a redirect so that tooling defaulting to `docs/plans/` (e.g. the `superpowers:writing-plans` and `superpowers:executing-plans` skills) finds the right path.

See `.claude/plans/` at the repo root for the canonical plan archive. Filename pattern: `YYYY-MM-DD-<slug>.md`.
